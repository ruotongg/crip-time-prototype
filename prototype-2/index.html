Critical design statement

The calendar performs neutrality — a grid, an administrative fact. But grids encode assumptions: that bodies run on schedule, that rest can be rescheduled without cost. Shredding this week is a small, irreversible refusal — made in the spirit of Cassandra Hradil's critical making. It doesn't destroy time. It refuses this version of it.
